# 开场演出预期效果

> 状态：视觉基准，供实现与验收使用
> 记录日期：2026-09-06
> 基准：`main` / `origin/main`

## 核心要求

点击主菜单“开始游戏”后，镜头沿一条固定、可重复的空间轨道，对画卷进行斜向俯视推进。运镜必须同时包含位置（Transform）和朝向（Rotation）的连续变化，镜头的观察目标始终是画卷中央。

四个关键帧完成后，镜头停在最后一帧并保持构图；只有在此时才开始播放画卷上的污染/墨迹动效。动效不能反过来驱动镜头，也不能在运镜过程中提前出现。

## 四张关键帧

| 阶段 | 参考图 | 预期画面 | 运镜含义 |
| --- | --- | --- | --- |
| K0：菜单初始帧 | [01](./reference/opening-keyframe-01-menu-paper-entry.png) | 主菜单仍在画面中，画卷以较小的倾斜平面出现在右下区域，四周保留大面积黑色背景。 | 固定的起始 Transform 与 Rotation；画卷不是正对镜头的平面。 |
| K1：进入画卷 | [02](./reference/opening-keyframe-02-oblique-approach.png) | 菜单退出，画卷变大并位于画面中下部，仍保持明显斜向俯视角。 | 镜头沿斜向轨道靠近，同时改变朝向；不能只做平移或简单缩放。 |
| K2：近景推进 | [03](./reference/opening-keyframe-03-close-oblique.png) | 画卷接近充满画面，边缘仍能看出倾斜，画面中心仍落在画卷主体中央。 | 继续沿同一轨道推进，观察目标不能漂移到画卷上部或边缘。 |
| K3：构图锁定 | [04](./reference/opening-keyframe-04-centered-lock.png) | 画卷完整、居中地占据主要画面，四周只留少量黑边；画面稳定后才进入动效。 | 运镜结束帧。锁定该 Transform + Rotation，不再发生额外位移或回弹。 |

关键帧的相对关系是硬性基准：K0 的画卷最小，K1 开始进入主体区域，K2 接近满幅，K3 居中锁定。实际运行不能出现“从画卷中央移向画卷上部”的替代运镜。

## 预期时序

```text
加载主菜单
  → 显示 K0 / 等待“开始游戏”
  → 点击开始，锁定菜单输入
  → 播放 K0 → K1 → K2 → K3 的固定相机轨道
  → 相机轨道完成回调
  → 保持 K3 构图
  → 播放污染/墨迹动效
  → 动效完成后再执行后续淡出或关卡切换
```

“相机轨道完成”是运镜和动效之间唯一的时序边界。不能用一个同时包含相机移动与污染材质的播放入口，让动效在 K3 之前提前启动。

## 实现约束

- 相机初始姿态和四个关键帧姿态必须来自同一套固定编排数据；每次 PIE、重新进入主菜单和重复点击开始时，都从 K0 恢复。
- 最终姿态必须是明确的 authored transform/rotation，不能根据上一次运行后的当前位置继续 `offset`，也不能把上一次运行的结果作为下一次运行的起点。
- 运行期间只允许一个系统拥有 Intro Camera 的视图控制权。不能在 Cine Camera、DefaultPawn、Player Camera Manager 和其他临时相机之间反复抢占视图。
- `DefaultPawn0` 不属于预期画面；相机引用失效时应停止本次演出并记录错误，不能静默回退到 Pawn 视角。
- 画卷外的黑色背景可以存在，但不应出现意外的全黑画面；全黑淡出只能发生在 K3 和污染动效之后的明确转场阶段。
- 动效触发应绑定在相机轨道完成事件上，而不是绑定在开始按钮点击、相机切换开始或任意固定延迟上。

## 验收标准

1. 连续重复 PIE 至少三次，K0 的画卷位置、大小和倾斜角一致，无累计偏移。
2. 播放过程中依次能辨认 K0、K1、K2、K3 四种构图，画卷尺寸和占屏比例按参考图逐步增大。
3. K1 至 K3 保持斜向俯视的运动方向，镜头始终朝向画卷中央，不偏移到上部。
4. K3 到达并稳定后，才出现污染/墨迹动效；运镜阶段画卷保持静态材质状态。
5. 演出中不出现 `DefaultPawn0`、意外全黑或镜头丢失；动效结束后的淡出、关卡切换不改变上述四帧基准。
