## 1. 已确认方案

### 参考基准

- 视觉基准采用第二张主菜单 HUD 参考图：简约水墨、横向飞白按钮条、右侧局部墨晕和低饱和朱砂选中提示。
- 最终布局将 HUD 整体放在屏幕左侧，因为开场演出初始帧的主要场景道具和视觉重心位于右侧。
- 参考图中的“画卷右移”只用于表达 HUD 与场景重心的关系；实施时不得为了适配 HUD 再移动实际场景中的画卷、道具或其他物件。
- 背景仍由开场演出的初始帧提供。HUD 是独立叠加层，不制作一张新的整屏背景。
- 水墨 panel 只作为独立透明叠加层，用于简化验收图中的植物细节；运行时水平镜像后锚定左侧边缘，不得替换或重排实际场景背景。

### 固定界面元素

只保留以下内容：

1. 游戏标题：`墨染开封`
2. 按钮：`开始游戏`
3. 按钮：`设置`
4. 按钮：`退出游戏`

不加入版本号、版权信息、制作组信息、加载提示、按键提示或其他菜单项。

## 2. 特殊硬性要求

### 2.1 不改动场景布局

- 不移动、缩放、旋转、删除或重排开场演出初始帧中的画卷、地图、建筑、角色、灯光道具及其他场景对象。
- 不修改开场演出的相机位置、镜头裁切、初始帧时间点、画面比例或演出轨迹。
- 不用重新绘制背景的方式“腾出”左侧空间；左侧 HUD 必须适配现有实际截图和最终初始帧。
- 允许的背景调整仅限于不改变几何构图的轻量打光：曝光、对比度、色调、全局分级，或 HUD 左侧下方的局部柔和明暗渐变。
- 如需局部渐变或墨晕，必须是可独立开关、可调透明度的 HUD/后处理辅助层，不得烘焙进场景布局或覆盖右侧主要道具。

### 2.2 字体沿用项目 HUD 字体

主菜单所有运行时绘制的文字沿用构筑 HUD 使用的项目字体，不新引入字体，不使用系统默认字体替代：

- UE 字体对象：`/Game/RawContent/UI/Fonts/AaGuDianKeBenSongYouMoBan_2_Font.AaGuDianKeBenSongYouMoBan_2_Font`
- 项目源文件：`Content/RawContent/UI/Fonts/AaGuDianKeBenSongYouMoBan_2.ttf`
- 现有构筑 HUD 的字体复用方式以 `CombatBuildDetailsWidget` 的 `SetTextStyle` 为准。

以下文字必须使用该项目 HUD 字体运行时绘制：

- `开始游戏`
- `设置`
- `退出游戏`
- 后续设置页、退出确认框中的所有新增文字

例外只有游戏标题：

- `墨染开封`继续使用已生成的艺术字图像。
- 标题艺术字作为独立透明纹理交付，不使用项目 HUD 字体重新排版。
- 标题不得烘焙进按钮底图或开场背景；按钮文字也不得烘焙进按钮底图。

## 3. 画面构成与布局要求

目标结构：

```text
左侧 HUD                                      右侧场景重心
┌────────────────────────────────────────────────────┐
│  墨染开封                                          │
│                                                    │
│  ─── 开始游戏 ─────────                            │
│  ─── 设置 ─────────────                            │
│  ─── 退出游戏 ─────────                            │
│                                      原场景画卷/道具 │
└────────────────────────────────────────────────────┘
```

- HUD 内容区锚定屏幕左侧，建议占屏幕宽度约 24%～30%。
- 左边缘保留安全边距，避免贴边；标题位于按钮组上方，三按钮垂直排列。
- 左侧 HUD 不得遮挡画面中央和右侧主要场景道具。
- 三个按钮宽度、字号、间距和基线保持一致；`开始游戏`为默认选中态。
- 按钮底图的运行时 CanvasSlot 尺寸固定为 `480 × 95`；文本继续居中放置在 button image 内部。
- 默认态以灰白宣纸/浅墨飞白呈现；选中态使用低饱和朱砂色小面积强调，不使用霓虹发光。
- 不制作覆盖全屏的暗色遮罩，不制作厚重卡片，不把左侧 HUD 做成不透明矩形墙。

## 4. 总体美术方向

沿用[战斗内构筑 HUD｜美术实施工单](./build-hud-art-implementation-work-order.md)已经确认的材质语言，但不直接复制构筑 HUD 的槽位和信息结构：

- 主色为墨黑、炭灰、宣纸白和暖灰。
- 飞白、断笔、干湿变化只用于按钮边缘和少量分隔线，不能破坏文字识别。
- 朱砂只用于默认选中、悬停或按下反馈；不作为大面积底色。
- 墨蓝只可作为极少量局部晕染，不作为主菜单的主要识别色。
- 画面整体保持留白和低信息密度，让开场演出初始帧继续承担主要叙事。
- 禁止英文、数字、版本号、占位符、科技风发光、复杂金色纹样和大面积装饰。

## 6. 标题艺术字要求

- 标题内容必须严格为：`墨染开封`。
- 保留生成参考图中的书写感、墨色和适度飞白，但要清理背景、边框、印章以外的无关元素。
- 输出透明 RGBA PNG，标题四周保留足够安全边距，避免 UMG 缩放时裁切笔锋。
- 如保留朱砂印章，印章必须是标题艺术字的一部分且不包含额外可读文字；不得出现版本号或英文字符。
- 标题图层独立于三个按钮，技术层可以单独调整位置、尺寸和透明度。

## 7. 按钮状态与文字要求

### 状态

- 默认态：浅灰/灰白飞白条，文字使用项目 HUD 字体和高可读暖白或深墨色。
- 悬停/键盘聚焦态：只增加少量朱砂标记、亮度或墨线强度；不放大到遮挡背景。
- 按下态：允许轻微缩放或位移反馈，但不改变按钮在布局中的占位关系。
- 三个按钮应共享同一套底图结构和边缘语言，不能各自使用完全不同的造型。

## 8. 透明通道与导入规范

- 所有 UI 源图使用 RGBA PNG，透明区域必须是真透明 alpha，不得用黑底、白底或棋盘格模拟。
- 标题、按钮和选中墨迹均独立成层，不把场景背景、画卷、地图或人物烘焙进去。
- 导入后确认 Texture Group 为 UI，alpha 保留，颜色空间和构筑 HUD 现有纹理保持一致。
- 主体四周保留约 8%～12% 安全边距，飞白和墨点不得被裁切。
- 不覆盖或替换现有构筑 HUD、技能 HUD 和商店 HUD 素材。
