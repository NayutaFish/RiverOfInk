## 2. 目标画面构成

### 2.1 整体气质

- 水墨、旧宣纸、飞白、干墨和低饱和暖灰为主体语言。
- 画面中央是纵向展开的墨铺卷轴，四周仍能看到游戏场景。
- 纸张主体为偏暖的灰白/米白，不能做成纯白科技面板。
- 黑色粗粝边框和毛笔撕边要有不规则变化，但不能侵入文字安全区。
- 顶部右侧保留少量朱印式红色装饰；红色只作点缀，不成为主色。
- 购买按钮使用黑色飞白墨条，保持手工刷痕和不规则边缘。
- 不使用霓虹蓝、金属科幻边框、渐变玻璃卡片或整屏不透明黑底。

### 2.2 版式基准

从上到下的结构必须保持如下顺序：

1. 标题“墨铺”和右上角纯墨余额/墨滴/朱印区域；
2. 五个等高商品行，中间以细弱的纸张分隔线分开；
3. 第二行在验收状态中只保留居中的“售罄”；
4. 底部中央黑色飞白“购买”按钮；
5. 购买按钮下方居中的“关闭”文字入口。

面板的具体屏幕尺寸由技术层适配，但不得改变验收图中的纵向阅读顺序、中央构图、行间距层级和底部按钮位置。

## 4. 制作要求

### 4.1 面板

- 面板外部必须是真透明 alpha，不能用黑色、白色或棋盘格模拟透明。
- 纸面纹理要有细密但克制的纤维/暗纹，缩小到实际显示尺寸后不能干扰汉字。
- 外框的黑色飞白和破损边缘要保留，但边缘不得裁切主体内容。
- 如果采用九宫格或分层拉伸，四角、顶部卷边和底部山水必须不变形；不能把整张图简单非等比拉伸。
- 面板不得烘焙商品行、余额、按钮、商品文案或售罄状态。

### 4.2 购买按钮

- 墨条要有明确的横向刷痕和不规则收笔。
- 按钮内保持足够留白，运行时文字居中叠加。
- 不制作独立的每商品购买按钮；最终画面只有一个全局购买按钮。
- 不包含 `购买`、价格、鼠标图标或键位字符。

### 4.3 墨滴与朱印

- 墨滴必须在小尺寸下仍能识别，黑灰轮廓优先于颜色。
- 朱印只作顶部装饰，不能与商品价格中的墨滴混淆。
- 两者均提供透明边距，避免 UMG 缩放时裁掉边缘。

### 4.4 分隔线与底部装饰

- 分隔线的对比度低于正文，不得抢走商品名称的视觉焦点。
- 山水/草木装饰应当淡化，不能遮挡第五行商品和关闭入口。
- 飞白、墨点和破损边缘服务于纸张轮廓，不能覆盖交互热区。

## 5. 导入规范

- 所有素材交付为 RGBA PNG，并保留真实 alpha。
- Texture Group 使用项目 UI 纹理约定，确认 alpha、颜色空间和压缩设置与现有 HUD 纹理一致。
- 在 Content Browser 中确认 PNG 已导入为同名 `.uasset`，不能只提交源 PNG。
- 文件放置在 `Content/RawContent/UI/Shop/`，不要覆盖现有 Build HUD、Reward HUD 或技能 HUD 资产。
- 每个资产应保留约 8%～12% 安全边距；购买按钮和分隔线的边缘尤其不能贴画布边界。
- 不把验收截图导入为运行时面板纹理；截图只保存在 `Content/reference/`。

1. PNG 与 UE `.uasset` 对照表；
