# 技能 HUD Icon 美术风格方案

## 定位

技能 Icon 是战斗 HUD 中的即时识别元素。玩家通常只会短暂扫视，因此需要保留现有技能 Icon 的高语义和高完成度：看到主体轮廓，就能判断技能的大致动作、能量和用途。

技能 Icon 可以比构筑 Icon 更华丽，但华丽必须服务于技能识别，不能变成装饰堆叠。

## 风格定义

**高语义的精制水墨 VFX 图标。**

以现有技能 Icon 的主体轮廓为语义母版，使用飞白、断笔和墨黑/留白/墨蓝进行重绘。它仍然应该像“技能效果的缩略图”，而不是纯抽象符号。

## 视觉组成

### 1. 主体轮廓

- 保留明确、集中、可快速识别的技能主体。
- 动作技能应有清晰方向，例如斜切、突进、旋转或聚束。
- 能量技能应有稳定的核心和外部边界。
- 主体应占据主要视觉面积，避免被飞溅和辅助笔触抢走。

### 2. 细节层级

建议控制在三层：

1. 主体剪影：决定技能是什么。
2. 内部留白或能量层：说明材质、方向或能量流动。
3. 少量飞白、断笔和墨点：补充速度与水墨质感。

不建议加入大量独立装饰元素。每一笔都应能解释为动作、能量或材质的一部分。

### 3. 色彩

- 墨黑：主体、冲击面和主要轮廓。
- 宣纸白：切口、内部能量和视觉焦点。
- 墨蓝：冷色能量、关键部位或技能状态。
- 如需其他属性色，应先确认不会破坏整体黑白墨色体系。

墨蓝应保持低饱和、偏哑光。可以有轻微能量感，但不使用霓虹辉光或强烈 Bloom。

### 4. 水墨处理

- 外轮廓允许轻微断裂和干笔。
- 内部可以有少量浓淡和笔锋变化。
- 飞溅应靠近主体，服务于速度或冲击。
- 避免大面积向外扩张的抽象墨浪。

## 与现有技能 Icon 的关系

现有技能 Icon 的优点应被保留：

- 中心主体集中；
- 蓝白对比明确；
- 有能量和材质层次；
- 缩小后仍有强剪影；
- 具备游戏技能 Icon 的完成度。

需要削弱的部分：

- 过多高光和发光边缘；
- 过度金属化或晶体化的材质；
- 与技能语义无关的装饰环；
- 过多细碎粒子和随机飞溅。

## 推荐结构

```text
透明背景
    ↓
集中、明确的技能主体
    ↓
一处内部留白或墨蓝能量层
    ↓
少量飞白与近身墨点
```

不要将每个技能都处理成“圆形墨圈 + 中央旋涡”。技能之间应根据具体动作保留不同的核心形状。

## 状态表现

状态变化应尽量与 Icon 本体分离：

- Normal：保持原始墨黑/留白/墨蓝关系。
- Selected：增加轻微墨蓝晕染或局部亮度，不改变主体轮廓。
- Cooldown：降低对比度或覆盖统一的冷却遮罩，不重绘 Icon。
- Disabled：降低饱和度和墨色密度，不添加新的灰色边框。

## 技术和构图要求

- 透明背景，1:1 构图。
- 主体四周保留足够安全边距，避免缩放时被裁切。
- 不包含文字、数字、技能键位和 HUD 面板。
- 优先保证目标尺寸下的剪影识别，再保留水墨纹理。

## 验收清单

- [ ] 缩小到实际技能 HUD 尺寸后，主体仍能一眼辨认。
- [ ] 去掉颜色后，动作方向和主体轮廓仍然成立。
- [ ] 视觉焦点集中在技能主体，而不是边缘飞溅。
- [ ] 蓝色是能量或状态提示，不是大面积装饰。
- [ ] 与其他技能并排时，主体形状不会互相混淆。
