# 构筑 HUD Icon 美术风格方案

> 最终执行风格：**飞白墨印图标风**。构筑 Icon 本体以黑、炭灰、宣纸白为主；墨蓝仅用于战斗 HUD 中“最近获得构筑”的独立背景衬托，不作为 Icon 本体的常规识别色。

## 定位

构筑 Icon 不需要像技能 Icon 一样准确描绘具体 VFX。它可以语义较弱、更加抽象，但必须保证同一组构筑 Icon 之间具有足够高的区分度。

核心原则：

> **弱语义，强轮廓；弱具象，强辨识。**

玩家不一定能仅凭一个构筑 Icon 说出它的完整效果，但应能迅速判断它与旁边的其他构筑不是同一个。

## 风格定义

**低具象、高区分度的飞白墨印机制符号。**

构筑 Icon 应像机制的视觉印记，而不是技能效果的缩略图。它可以提示切割、聚束、环绕、追踪、分裂或叠加等行为，但不需要画出具体武器、弹体或人物。

## 组内区分规则

构筑 Icon 的区分优先级固定为：

1. **宏观外轮廓**：斜刃、开放环、聚束、分裂、放射、钩形等。
2. **内部负形**：中心孔、纵向裂隙、偏心缺口、双层留白等。
3. **动势方向**：单向切割、向心收束、环绕追踪、向外扩散或上下叠加。
4. **墨迹密度**：厚重块面、细线轨迹、点状聚集等。
5. **颜色和亮度**：只作为最后一级辅助，不作为主要区分依据。

同一组中，不应出现两个同时拥有“圆形墨圈、中央旋涡、相同墨蓝位置”的 Icon。

## 视觉组成

### 1. 共同家族语言

所有构筑 Icon 可以共享：

- 墨黑主体；
- 宣纸白负形；
- 低饱和墨蓝小面积强调；
- 飞白、断笔和干湿变化；
- 统一画布比例和安全边距。

共享的是材质和完成度，不是同一套轮廓模板。

### 2. 单个 Icon 的结构

建议每个构筑 Icon 由以下部分组成：

- 一个唯一的主轮廓；
- 一个能强化差异的内部负形；
- 一种明确的动势方向；
- 少量辅助墨点或断笔。

不建议使用过多外扩笔触。构筑 Icon 需要在组内快速比较，因此主体必须集中，不能让每个 Icon 都变成满画布的墨迹爆发。

### 3. 语义抽象程度

构筑 Icon 可以从具体对象退后一级：

- 不画“箭矢”，画向前聚束的尖锐轨迹；
- 不画“锁定准星”，画偏心收束的墨环和目标核心；
- 不画“爆炸”，画向外分裂的墨块；
- 不画“多发子弹”，画有节奏的点状聚束。

这样可以保留机制暗示，同时避免与技能 Icon 争夺具体语义。

## 色彩和状态

- 墨黑、留白是默认识别基础。
- 墨蓝只用于少量机制焦点、选中状态或特殊稀有度。
- 不允许仅通过颜色区分两个构筑。
- Selected 状态可以增加一笔淡墨蓝晕或局部染色，但不能改变 Icon 的宏观轮廓。
- Locked、Unavailable 等状态使用统一遮罩或透明度规则，不为每个 Icon 设计独立灰阶版本。

## 推荐的差异化形态

以下是形态方向示例，不是固定图标清单：

| 机制倾向 | 推荐宏观形态 | 主要区分点 |
| --- | --- | --- |
| 切割 / 穿透 | 长斜刃或窄楔形 | 方向和尖锐负形 |
| 追踪 / 锁定 | 偏心开放环 + 目标核心 | 缺口位置和收束方向 |
| 聚束 / 弹幕 | 前端核心 + 短轨迹 | 主体与轨迹的前后关系 |
| 分裂 / 多段 | 分离的双块或扇形 | 间距和分裂轴线 |
| 范围 / 扩散 | 不对称放射形 | 外扩方向和空白区域 |
| 叠加 / 强化 | 多层平行或嵌套墨带 | 层数、间距和厚度 |

这些形态只表达机制倾向，不需要还原成具体技能画面。

## 与技能 Icon 的关系

技能 Icon 可以保持当前较高的视觉完成度和语义强度。构筑 Icon 不应被理解为“技能 Icon 的简化低配版”，而是更高层级的系统符号。

两者的关系应是：

```text
技能 Icon：具体效果 / 高语义 / 精制 VFX
       ↓ 归纳
构筑 Icon：机制印记 / 弱具象 / 强组内区分
```

同一构筑可以关联一个或多个技能 Icon，但构筑 Icon 不需要复制技能 Icon 的主体形象。

## 尺寸与验收

构筑 Icon 需要进行组内测试，而不是只单独检查：

- [ ] 放入完整构筑列表后，任意相邻两个 Icon 都能快速区分。
- [ ] 去掉颜色后仍能区分。
- [ ] 只保留黑色剪影时仍能区分。
- [ ] 缩小到目标显示尺寸后，宏观轮廓没有合并。
- [ ] Icon 的差异来自轮廓、负形和动势，而不是细碎纹理。
- [ ] 同一组中没有重复的“圆环 + 旋涡”模板。
- [ ] 视觉纹理不会超过主体语义的识别优先级。

## 生成和制作约束

- 透明背景，1:1 构图。
- 无文字、数字、键位、面板或装饰边框。
- 每个 Icon 只保留一个主形、一个主要负形和少量辅助笔触。
- 先建立一组互不混淆的轮廓，再统一水墨材质。
- 不用蓝色、发光或稀有度边框制造假区分。
