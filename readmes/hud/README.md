# HUD Icon 美术方案

> 状态：方案已确认，待美术与技术实施
>
> 目标：为技能 HUD Icon 与构筑 Icon 建立可独立演进、但能共存于同一 HUD 的美术规范。

## 核心结论

技能 Icon 与构筑 Icon 不要求采用相同的图形方案。两者服务的阅读任务不同：

- 技能 Icon 是“高语义、高完成度”的技能效果缩略图，优先让玩家立刻认出当前技能。
- 构筑 Icon 是“弱具象、高区分度”的机制符号，允许语义抽象，但同一组内必须容易区分。

两者共享的是材质语言，而不是具体轮廓：

- 墨黑作为主体色；
- 宣纸白作为留白和高光；
- 低饱和墨蓝作为少量强调；
- 适度使用飞白、断笔和干湿变化；
- 透明背景、无文字、无额外 UI 边框。

## 方案对照

| 维度 | 技能 Icon | 构筑 Icon |
| --- | --- | --- |
| 主要任务 | 识别当前技能和效果 | 区分不同构筑并提示机制类型 |
| 语义强度 | 高 | 可弱化 |
| 视觉重点 | 主体形象、能量、材质和动作 | 宏观轮廓、负形、动势和组内差异 |
| 装饰程度 | 可精致，但不能遮蔽主体 | 克制，避免模板化装饰 |
| 色彩作用 | 可参与表现技能属性 | 只作辅助状态，不承担主要区分 |
| 统一方式 | 共享水墨材质和色彩 | 共享水墨材质和色彩 |

## 共通验收要求

- Icon 在目标显示尺寸下仍然有清晰主体。
- 黑白版本仍能读取主要轮廓。
- 墨蓝不是大面积填充，也不是唯一识别手段。
- 不出现文字、数字、复杂边框或与 HUD 无关的背景。
- 生成图中的纹理应服务于轮廓，而不是把轮廓打散。
