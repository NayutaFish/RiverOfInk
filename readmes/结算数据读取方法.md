# 结算数据读取方法

> `USettlementDataRecorder`（`Source/RiverOfInk/Script/Core/SettlementDataRecorder.h`）是静态类：模块加载时自动订阅战斗/经济/选卡事件并累计数据，外部只负责读。

## 数据项与读取接口

| 数据 | 接口 |
| --- | --- |
| 击杀（含精英） | `GetNonPlayerDeathCount()` |
| 精英击杀 | `GetEliteEnemyDeathCount()` |
| 累计伤害 | `GetTotalDamageDealtToNonPlayer()` |
| 累计货币 Ink | `GetTotalShopCurrencyGained()` |
| 累计购买次数 | `GetShopPurchaseCount()` |
| 全部增益（含层数） | `GetRewardPicks()` → `TArray<FSettlementRewardPick>` |
