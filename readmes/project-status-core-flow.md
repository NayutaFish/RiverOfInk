## 当前链路

| 环节 | 当前情况 |
|---|---|
| 主菜单 | `MainMenu`为默认地图；主菜单开场导演、Level Sequence、墨迹遮罩和开始游戏回调已有。最终开场内容仍待开发/验收。 |

| 房间序列 | 默认3个大阶段，每阶段3个房间：Combat A → 标记为Boss的Combat B → Shop。商店固定在阶段末位。 |
| 战斗房间 | 房间管理器负责出生点、敌人生成、开战、清场和奖励触发。 |
| 奖励阶段 | 清场后进入Reward，奖励应用后进入Completed；技能修正、Pure Ink和生命奖励已有基础。 |
| 商店阶段 | 进入商店后开放J键交互，Esc关闭；购买完成后可通过出口继续。商品数量与显示槽位存在不一致。 |
| 房间切换 | 出口触发RunFlow进入下一房间/阶段；当前主要是地图加载与基础淡入淡出。 |
| 结果 | 最后一阶段胜利可进入Result；失败分支尚未形成完整闭环。 |

## 流程判断

**主链路基本成立：**`MainMenu → Preparation → LoadingRoom → InRoom → Combat → Reward → Completed → Exiting → 下一房间/阶段`。

**尚未闭环的关键点：**

- 玩家死亡事件已发布，但当前未发现完整的失败处理订阅、Defeat结果界面和重启链路。
- 胜利结果已有处理，失败结果和Result阶段内容需要补齐。
- 商店5个默认商品与3个可见UI槽位不匹配，影响实际购买覆盖。
- Boss只是流程标签，当前没有独立Boss关卡内容。
- 关卡转换目前以基础淡入淡出为主，专门的转换演出尚未完成。
